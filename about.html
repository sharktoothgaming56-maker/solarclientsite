About SolarClient

What this project is, who makes it, how it is paid for, and what we will and will not do with it.

What SolarClient is

SolarClient is a free Minecraft: Java Edition launcher for Windows, built around one idea: most players want better performance and a few quality-of-life features, and should not have to assemble a mod stack by hand to get them.

Concretely, it does four things. It manages Java, downloading the correct Eclipse Temurin runtime for whichever Minecraft version you pick, so you never install or configure Java yourself. It ships a curated performance mod stack — Sodium, Lithium, FerriteCore and others — already version-matched and configured. It tunes the JVM, generating garbage collector flags scaled to your chosen memory allocation rather than leaving you with defaults designed for server throughput. And it adds a mod browser, HUD editor and waypoint system for the things people end up wanting anyway.

None of that is magic, and we try not to describe it as if it were. The performance mods are open source, freely available from Modrinth, and work perfectly well installed by hand. The JVM flags are public knowledge. What the launcher sells — except that it does not sell anything — is not having to do it yourself, and not having to redo it every time Minecraft updates.

Who makes it

SolarClient is made by a small independent team of Minecraft players. It started, as these things usually do, because we wanted a better launcher for ourselves and the existing options each had something we did not want — mandatory telemetry, a cosmetics store, a proprietary mod system, or simply more weight than we needed.

We are not a company. There is no funding round behind this, no support desk, and no service level agreement. What there is: an actively maintained project, a Discord server where the people who write the code read the messages, and a public release history on GitHub that you can check for yourself rather than taking our word for.

We think being clear about that is more useful than presenting a small project as something larger. If you need the assurances that come with a funded team — code-signed installers, guaranteed support response times, a long track record — the bigger clients genuinely offer those and we are not going to pretend otherwise.

How it is funded

This website displays advertising through Google AdSense. That is the entire business model, and it pays for domain registration, hosting, and the time that goes into development and into the guides published here.

Some consequences of that we want to state plainly:

The launcher sends no telemetry. It does not report what you play, when you play it, or anything about your machine. Your settings, session token, waypoints and HUD layout stay on your computer. We do not run servers that store user data, which means there is no user data to sell even if we wanted to.

The website does use cookies for advertising. Google and its partners set them to measure and personalise the ads you see. We are not going to bury that in a footer — it is how this works, and the cookie policy explains exactly what is set and how to opt out of personalisation.

There is no premium tier and there will not be one. No paid cosmetics, no subscription, no feature held back for a paying version. If that ever changes, it will be announced clearly rather than discovered.

What we will not do

It is easier to trust a project that says where its limits are, so here are ours.

No cheats. SolarClient contains no combat automation, no X-ray, no movement exploits, and no anti-cheat evasion. This is not a “not yet” — a performance launcher and a hacked client are different products and we are only building one of them.

No cracked account support. Authentication goes through Microsoft’s official OAuth flow. You need an account that owns the game. We will not add offline-mode account spoofing.

No asking for your password. The launcher never sees your Microsoft credentials, and no legitimate Minecraft client ever needs them. If any launcher or website asks you to type your Microsoft password into its own form, close it.

No bundled extras. The installer installs SolarClient. It does not install a toolbar, a search hijacker, a “partner offer”, or a download manager. Verify the SHA-256 on the home page against your file if you want to confirm that.

No pretending about the SmartScreen warning. The installer is not code-signed, Windows will warn you, and we explain why on the home page rather than hoping you do not notice.

Why we publish guides

The guides section exists because the same questions kept arriving in Discord, and because a large amount of what is published about Minecraft performance is confidently wrong. “Allocate 16 GB of RAM” is repeated constantly and makes stutter worse. Optimiser utilities that promise frame rates do nothing. JVM flag lists get copied forward for a decade after the flags stopped existing.

So the guides try to explain mechanisms rather than hand out steps, and they deliberately describe techniques that work without our launcher — because they do, and claiming otherwise would be a good way to lose the trust that makes the guides worth reading.

If you find an error in one, tell us. Corrections get made.
