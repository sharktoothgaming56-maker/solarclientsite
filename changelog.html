Release Changelog

Every SolarClient release, pulled live from GitHub. This page reflects what actually shipped — it reads the release history directly rather than a list we maintain by hand and forget to update.

How releases work

SolarClient releases are published to GitHub Releases, and every build carries a SHA-256 hash so you can verify the file you downloaded matches what was uploaded. The download button and hash on the home page read from the same source, which is why they never go stale.

Version numbers follow a major.minor.patch scheme. Patch releases fix bugs and update bundled mods. Minor releases add features or support for a new Minecraft version. Major releases change something structural about the launcher itself.

The launcher checks for updates on startup and can install them in place, so in normal use you do not need to return here — this page is for reading what changed, and for getting an older build if you need one.

The in-game SolarClient mod is versioned separately from the launcher and ships on a rolling mod tag rather than as a numbered release, so it does not appear in the list below. The launcher fetches the matching mod build for your Minecraft version automatically; you do not need to download it yourself.

Ongoing work

Things currently being worked on or seriously considered. This is a statement of intent, not a set of promises with dates attached — a small team missing announced deadlines helps nobody.

Cross-platform support. macOS and Linux builds are the most requested thing by a wide margin. The launcher shell is portable; the Java runtime management and installer work are not, and that is the actual effort.

Code signing. A signing certificate would remove the SmartScreen warning that currently greets every new user. It costs several hundred dollars a year, which is the constraint.

Modpack import. Reading existing CurseForge and Modrinth pack formats so you can bring a pack across instead of rebuilding it.

Opening parts of the source. Under consideration, without a timeline.

Priorities are genuinely shaped by what people ask for in Discord. If something here matters to you, saying so has more effect than you would expect on a project this size.
