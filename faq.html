Frequently Asked Questions

Everything we get asked regularly about SolarClient — safety, accounts, mods, platforms, and how it compares to other launchers. If your question is not here, ask us directly.

Safety and trust

Every release is published on GitHub with its SHA-256 hash, so you can verify that the file you downloaded is byte-for-byte what was uploaded. A VirusTotal link for the current build is on the home page and updates automatically with each release.

Because the installer is not code-signed, Windows SmartScreen shows a one-time warning. That is standard for unsigned independent software and does not indicate a problem with the file — code signing certificates cost several hundred dollars a year, which a free project funded by website ads does not currently cover. We would rather be upfront about that than pretend the warning does not happen.

We encourage you to verify the hash before running any installer you download, from us or anyone else. The home page shows you exactly how.

Windows shows that for any application without a code signing certificate. It is a statement about whether we have paid a certificate authority, not about whether the file is safe. Click “More info”, then “Run anyway”. Windows remembers the choice for that file.

If you would rather verify first, run Get-FileHash against the downloaded installer in PowerShell and compare the result to the SHA-256 shown on our home page.

The launcher does not send telemetry. Your settings, session token, waypoints and HUD layout are stored locally on your machine. We do not operate servers that store user information, and we do not track your usage of the application.

This website is a different matter and we are explicit about it: it displays Google AdSense ads, and Google sets cookies to measure and personalise them. That is how hosting and development are paid for. Full detail is in our privacy policy and cookie policy, including how to opt out of personalised advertising.

Yes, because we never see it. SolarClient uses Microsoft’s official OAuth flow — the same one the vanilla launcher uses. You log in on a Microsoft page, and Microsoft hands back an access token. Your password never passes through the launcher or through us.

Be extremely wary of any Minecraft launcher, client or website that asks you to type your Microsoft password into its own form. That is not how Minecraft authentication works, and it is how accounts get stolen.

Mods and features

Yes. SolarClient’s bundled mods are ordinary Fabric and Forge mods, not a proprietary system. You can add your own through the built-in browser, which searches Modrinth and CurseForge, or by dropping .jar files into the mods folder directly. The launcher checks version and loader compatibility to catch the obvious conflicts before they crash you.

The core stack is Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling and ModernFix, version-matched to whichever Minecraft release you select. What exactly ships depends on the version, since not every mod supports every release.

All of them are open source and freely available from Modrinth. Nothing here is exclusive to SolarClient — the launcher's job is keeping them consistent across versions, which is tedious rather than difficult. Our performance mod reference explains what each one does.

Not simultaneously with the default profile. SolarClient uses Sodium, and Sodium and OptiFine both replace the rendering engine, so they cannot run together.

For most purposes Sodium plus Iris is the better option — higher frame rates and far better mod compatibility. If you specifically need OptiFine, create a separate profile without the built-in performance mods. Our comparison guide covers when OptiFine is still genuinely the right choice.

No. SolarClient is a performance launcher with quality-of-life features — a HUD editor, waypoints, a mod browser. It contains no combat automation, no X-ray, no movement exploits, and no anti-cheat evasion, and we are not going to add any.

Everything it bundles is allowed on the large majority of servers, but server rules differ and they are the authority. If a server disallows a client-side mod, do not use it there.

The bundled mods are standard, widely used performance and HUD mods that the overwhelming majority of servers permit. We are not aware of any general prohibition on them.

That said, individual servers set their own rules, and some competitive servers restrict things like minimaps or waypoint systems. Check the rules of the server you play on. You can disable individual features in Settings if a server you care about asks you to.

The project

It is free, with no premium tier, no cosmetics store, and no paid features. The catch, such as it is, is that this website carries advertising, and that is what pays for hosting and development time.

The launcher itself does not display ads from this website's ad network, and the application is not funded by selling anything about you — it sends no telemetry at all.

The launcher itself is not, currently. It is built on top of open-source performance mods whose licences we respect and comply with, and release binaries are published on GitHub with SHA-256 hashes so you can verify what you are running.

We are considering opening parts of the project. We would rather say “considering” honestly than promise a date we might not meet.

Mainly in being smaller and more transparent. SolarClient uses standard Fabric and Forge mods that you can inspect, replace, or add to, rather than a proprietary bundled mod system. There is no mandatory telemetry, no cosmetics store, and no premium tier.

The larger clients have real advantages too — bigger teams, longer track records, broader platform support, and code-signed installers. We are not going to pretend otherwise. If those matter more to you than the things above, they are a reasonable choice.

Windows Settings → Apps → Installed apps, find SolarClient, click Uninstall. That removes the launcher, its managed Java runtimes, and cached assets.

Your Minecraft worlds and saves live in the standard .minecraft folder and are not touched by uninstalling. Nothing you built goes anywhere.

Releases are published through GitHub Releases as they are ready, which in practice means when a Minecraft version ships, when the bundled mods update, or when a bug worth fixing gets reported. The changelog pulls the real release history directly from GitHub, so it reflects what actually shipped rather than what we remembered to write down.
