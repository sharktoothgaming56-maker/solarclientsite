What is SolarClient?

SolarClient is a custom Minecraft launcher built to give players the tools that Lunar Client and Feather offer, without the bloat. Everything is built in-house the launcher, the in-game mod, the HUD editor, and the waypoint system.

We build features players actually ask for, ship them fast, and keep the whole thing free. The project is actively developed and updated regularly the download above is a real, working build, not a placeholder.

FAQ

Is SolarClient safe? ▼
The installer’s SHA‑256 hash is published above so you can verify it against the downloaded file and view the live VirusTotal report. Because the build isn’t code‑signed, Windows SmartScreen shows a warning the first time you run it see the setup steps below.
Do I need to install Java? ▼
No. SolarClient downloads and runs the exact Java version required for each Minecraft version automatically.
Do I need a Minecraft account? ▼
Yes. You log in through your standard Microsoft account to join servers and play.
