Mods, friends, versions, themes. All in one launcher.

  1. 01

    Launchpad

    Knows your rig before the first launch.

    SolarClient reads your CPU, GPU and RAM, rates the machine and suggests how much memory Minecraft should get. One button installs the performance mods for your loader and tunes them to your hardware.

    • Hardware tier and memory recommendation
    • “Install all & auto-tune” for Fabric instances
    • Levels that grow with playtime, Coal to Netherite
  2. 02

    Content

    Find a mod, press Install, play.

    Search Modrinth for mods, modpacks and resource packs without opening a browser. Results are filtered to the instance you are installing into, so you only see what runs on that version and loader.

    • Import and export modpacks
    • Sync mods over from another instance
    • Drop in your own .jar or resource pack

    Versions

    Every release, kept apart.

    From the newest 26.x releases back through 1.21, 1.20 and older. Each instance has its own mods, memory and Java runtime, so a PvP setup and a 200-mod pack never step on each other.

    • Vanilla and Fabric instances
    • Separate mods, RAM and Java per instance
    • Game files download over 24 connections
  4. 04

    • Live presence: online, in game, which instance
    • DMs and group chats with replies and edits
    • Blocking and reporting built in
  5. 05

    • Everything saves automatically

Garbage collection tuned to your memory

Custom G1GC flags, scaled to the memory you allocate, cut the collection pauses that show up as stutter in PvP, chunk loading and big modpacks. No JVM arguments to research or paste — the RAM guide explains what they do.

24 downloads at once

Assets, sounds and libraries come down in parallel, so a fresh install usually finishes in well under a minute on broadband.

It downloads the exact Eclipse Temurin runtime each version needs, keeps them side by side and removes ones nothing uses. See the Java version chart.

Official Microsoft sign-in

The same Microsoft and Xbox OAuth flow the vanilla launcher uses. You type your password on Microsoft’s page; it never reaches the launcher or our servers.

A curated performance stack

Sodium, Lithium, FerriteCore and friends, version-matched to your release. How much faster depends on your hardware — the FPS guide explains why.

Built-in HUD editor

Waypoints across dimensions

Set, share and navigate to waypoints with in-game distance markers. They persist between sessions, so a forgotten coordinate never costs you a base again.

How it works

From download to in‑game in three steps.

No terminal commands, no manual file management, no Java headaches.

1

Download and install

Run the installer from this page. SolarClient installs into its own directory, fetches the correct Java runtime for the version you choose and pre-configures the optimisation mods. A couple of minutes on a typical connection.

2

Sign in with Microsoft

Authenticate through Microsoft’s official OAuth flow — the same one the vanilla launcher uses. Your session token stays on your PC and is refreshed securely when it expires.

3

Pick a version and play

Choose a version. SolarClient applies the tuned JVM flags, loads the performance mods and launches. Add mods, shaders or resource packs any time from the built-in browser.

First launch on Windows

About the blue Windows warning.

This build is not code-signed, so Windows SmartScreen flags it the first time you run it. That is standard for independent software without a signing certificate and does not indicate a problem with the file — but you can check the SHA-256 at the top of this page before continuing.

1

Verify the hash (recommended)

In PowerShell, run Get-FileHash .\SolarClient-Setup-*.exe and compare it to the SHA-256 above. If they match, the file is exactly what was published on GitHub.

2

Click “More info”, then “Run anyway”

SmartScreen shows this for every unsigned application. Once you click through, Windows remembers your choice for this file.

3

Follow the installer

Keep the default folder or choose your own, let it finish, and open SolarClient from the desktop shortcut or Start menu.

4

Sign in and play

Sign in with Microsoft, pick a version and press Launch. Java, mods and JVM flags are handled on first launch.

About

What is SolarClient?

SolarClient is a custom Minecraft launcher built as an alternative to Lunar Client, Feather and similar performance clients. The goal is straightforward: give players the performance tools and quality-of-life features they want, without the bloat, telemetry or locked-down ecosystems that come with the bigger clients.

Rather than wrapping someone else’s work in a new interface, SolarClient assembles a curated stack of open-source performance mods — Sodium, Lithium, FerriteCore and others — and combines them with custom JVM tuning, a parallel asset downloader and a built-in Modrinth browser. The launcher shell, the HUD editor and the waypoint system are built in-house.

Everything is published through GitHub Releases, and the download button, SHA-256 hash and VirusTotal link on this page read from that release automatically — so they update themselves and this page never goes stale.

Why is it free? SolarClient is a passion project by a small team of Minecraft players who wanted a better launcher for themselves. This website runs Google AdSense to cover hosting and development; the launcher shows a few ads of its own and sends no usage analytics.
