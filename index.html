Built for Performance and Gameplay

Every part of SolarClient is aimed at one thing: getting the smoothest Minecraft you can out of the hardware you already have, whether that is a budget laptop or a high-end desktop.

A Curated Performance Stack

Pre-configured with Sodium, Lithium, FerriteCore, EntityCulling, ImmediatelyFast and ModernFix, version-matched to your Minecraft release. Most players see a large frame rate improvement on first launch without changing a single setting — how large depends on your hardware, and our FPS guide explains why.

Garbage Collector Tuning

Custom G1GC flags, scaled to the memory you allocate, that cut the pauses causing stutter during PvP, chunk loading and heavy modpack sessions. No JVM arguments to research or paste. The RAM guide covers what the flags do.

One-Click Mod & Shader Browser

Search and install mods, shaders and resource packs from Modrinth and CurseForge without leaving the launcher. Everything is matched against your game version, loader and existing mods to catch conflicts before they crash you.

Automatic Java Setup

Never install or configure Java again. SolarClient downloads the exact Eclipse Temurin runtime each Minecraft version needs, keeps several side by side, and removes ones nothing uses. See the Java version chart for what it is doing behind the scenes.

Official Microsoft Authentication

Log in through Microsoft and Xbox OAuth — the same flow Mojang’s own launcher uses. Your password is never typed into the launcher and never reaches our servers, because we do not run any that could receive it.

Parallel Asset Downloads

Game assets, sounds and libraries download over 24 simultaneous connections. A first-time install that would otherwise take several minutes typically finishes in well under one on a broadband connection.

Built-in HUD Editor

Drag and drop an FPS counter, coordinates, keystrokes, CPS, armour status and more anywhere on screen. Save several layouts and switch between them per game mode or per profile.

Waypoint System

Set, share and navigate to waypoints across dimensions, with in-game distance markers. Waypoints persist between sessions, so you stop losing bases to a forgotten coordinate.

Profiles That Stay Separate

Keep a lightweight PvP setup, a shader-heavy survival world and a 200-mod kitchen-sink pack in parallel, each with its own mods, memory allocation, Java runtime and HUD layout.

How SolarClient Works

From download to gameplay in three steps. No terminal commands, no manual file management, no Java headaches.

1

Download and install

Run the installer from this page. SolarClient installs into its own directory, fetches the correct Java runtime for the Minecraft version you choose, and pre-configures the optimisation mods. The whole process takes a couple of minutes on a typical connection.

2

Log in with Microsoft

Authenticate through Microsoft’s official OAuth flow — the same one the vanilla launcher uses. SolarClient never sees or stores your password. Your session token is kept locally and refreshed securely when it expires.

3

Pick a version and play

Choose your Minecraft version. SolarClient applies the tuned JVM flags, loads the performance mods, and launches. Add more mods, shaders or resource packs any time from the built-in browser without restarting.

What Is SolarClient?

SolarClient is a custom Minecraft launcher built as an alternative to Lunar Client, Feather and similar performance clients. The goal is straightforward: give players the performance tools and quality-of-life features they want, without the bloat, telemetry or locked-down ecosystems that come with the bigger clients.

Rather than wrapping someone else’s work in a new interface, SolarClient assembles a curated stack of open-source performance mods — Sodium, Lithium, FerriteCore and others — and combines them with custom JVM tuning, a parallel asset downloader, and a mod browser that pulls from Modrinth and CurseForge. The launcher shell, the HUD editor and the waypoint system are built in-house.

Everything is published through GitHub Releases, and the download button, SHA-256 hash and VirusTotal link on this page read from that release automatically — so they update themselves and this page never goes stale.

Why is it free? SolarClient is a passion project by a small team of Minecraft players who wanted a better launcher for themselves. This website runs Google AdSense to cover hosting and development; the launcher itself contains no advertising and sends no telemetry.
