Built for Performance and Gameplay

Every component of SolarClient is tuned to give you the smoothest Minecraft experience possible, whether you play on a budget laptop or a high-end desktop.

2x–4x FPS Multiplier

Pre-tuned with Sodium, Lithium, FerriteCore, Entity Culling, ImmediatelyFast, and ModernFix to squeeze maximum frames out of your hardware. Most players see their FPS double on the first launch without changing any settings.

Zero-Stutter G1GC Tuning

Custom JVM memory flags prevent garbage-collection lag spikes during PvP, render-distance loading, and heavy modpack sessions. The launcher automatically applies the right flags for your allocated RAM so you never have to touch a JVM argument.

One-Click Mod & Shader Browser

Search and install mods, shaders, and resource packs from Modrinth and CurseForge without leaving the launcher. Everything auto-matches your game version, loader, and existing mods to prevent conflicts.

Automatic Java Setup

Never install or configure Java manually again. SolarClient downloads the exact Adoptium runtime each Minecraft version needs, manages multiple Java installations side by side, and cleans up old ones automatically.

Official Microsoft Auth

Log in safely using official Microsoft and Xbox OAuth—the same authentication flow Mojang’s own launcher uses. Your password and credentials never touch our servers or the launcher’s local storage.

24 Parallel Downloads

Game assets, sound files, and libraries download over 24 simultaneous connections, turning a 10-minute first-time install into under 60 seconds on most broadband connections.

Built-in HUD Editor

Drag and drop HUD elements—FPS counter, coordinates, keystrokes, CPS, armor status, and more—anywhere on your screen. Save multiple layouts and switch between them for different game modes.

Waypoint System

Set, share, and navigate to waypoints across dimensions. Coordinates display in-game with distance markers, and your waypoints persist across sessions so you never lose a base or landmark again.

Grab the installer from this page and run it. SolarClient installs into its own directory, downloads the correct Java runtime for your chosen Minecraft version, and pre-configures all optimization mods automatically. The entire process takes under two minutes on a typical connection.

What Is SolarClient?

SolarClient is a custom Minecraft launcher created as an alternative to Lunar Client, Feather, and similar performance clients. The goal is simple: give players the performance tools and quality-of-life features they want, without the bloat, telemetry, or locked-down ecosystems that come with bigger clients.

Everything is built in-house—the launcher shell, the in-game mod integration, the HUD editor, and the waypoint system. Rather than wrapping someone else’s work in a new UI, SolarClient assembles a curated stack of open-source performance mods (Sodium, Lithium, FerriteCore, and others) and combines them with custom JVM tuning, a parallel asset downloader, and a streamlined mod browser that pulls from Modrinth and CurseForge.

The project is actively developed and updated regularly. New releases are published through GitHub Releases, and the download button, SHA-256 hash, and VirusTotal link on this page update themselves automatically whenever a new build is pushed. This means you always get the latest version without this site ever going stale.

Why free? SolarClient is a passion project by a small team of Minecraft players who wanted a better launcher for themselves and decided to share it. The site runs ads through Google AdSense to cover hosting and development costs, but the launcher itself contains no ads and never will.

Advanced Minecraft Optimization Guide

Understanding how SolarClient maximizes your framerate behind the scenes.

Why Vanilla Minecraft Struggles with FPS

Vanilla Minecraft relies heavily on a single CPU thread for its rendering pipeline and game logic. As you increase your render distance or explore complex environments, this single-thread bottleneck causes GPU underutilization and severe frame drops. SolarClient integrates modern rendering engines like Sodium, which completely rewrites the OpenGL rendering pipeline to utilize multi-threading and modern graphics APIs, allowing your GPU to finally stretch its legs.

The Importance of JVM Garbage Collection

Micro-stutters (where your game freezes for a fraction of a second every few minutes) are usually caused by Java's Garbage Collector (GC) cleaning up memory. SolarClient automatically implements advanced Generational ZGC and tuned G1GC arguments based on your system RAM. By controlling the pause times and heap region sizes, SolarClient ensures that memory cleanup happens seamlessly in the background without interrupting your gameplay.

Managing Mod Conflicts & Memory Leaks

Installing too many mods without proper optimization leads to memory leaks. SolarClient bundles FerriteCore and memory-leak-fix mods to aggressively reduce the RAM footprint of block states and models. This means you can play longer sessions on multiplayer servers without your RAM usage slowly ballooning until the game crashes.

Frequently Asked Questions

Answers to the most common questions we get from players. If yours isn’t listed here, ask in our Discord.

Is SolarClient safe to use? ▼
Every release is published on GitHub with its SHA-256 hash, so you can verify the file you downloaded matches what was uploaded. A direct VirusTotal link is provided above for each build. Because the installer is not code-signed, Windows SmartScreen will show a one-time warning—this is standard for unsigned indie software and does not indicate a security issue. We encourage you to verify the hash before running the installer.
Do I need to install Java separately? ▼
No. SolarClient automatically downloads and manages the correct Adoptium Java runtime for each Minecraft version. If you switch from 1.8.9 to 1.20.4, the launcher will fetch the right Java version in the background without any input from you. You can also point the launcher at a custom Java installation in Settings if you prefer.
Do I need a Minecraft account? ▼
Yes. You need a legitimate Microsoft account that owns Minecraft: Java Edition. SolarClient authenticates through Microsoft’s official OAuth flow, the same method the vanilla launcher uses. We do not support cracked or offline accounts.
Can I use my own mods alongside SolarClient’s built-in ones? ▼
Yes. SolarClient’s built-in mods are standard Fabric/Forge mods. You can add your own mods through the built-in mod browser (which searches Modrinth and CurseForge) or by dropping .jar files into the mods folder. The launcher checks for version and loader compatibility to help prevent conflicts.
Does SolarClient work with OptiFine? ▼
SolarClient uses Sodium instead of OptiFine for rendering optimization, as Sodium generally delivers higher frame rates and is compatible with a wider range of mods. OptiFine and Sodium cannot run simultaneously because they both replace the rendering engine. If you specifically need OptiFine for a shader pack that only supports it, you can create a separate profile in the launcher without the built-in performance mods.
How do I uninstall SolarClient? ▼
Open Windows Settings → Apps → Installed Apps, find “SolarClient,” and click Uninstall. This removes the launcher, its managed Java runtimes, and cached assets. Your Minecraft worlds and saves are stored in the standard .minecraft folder and are not affected by uninstalling SolarClient.
Is SolarClient open source? ▼
The launcher itself is not open source at this time, but it is built on top of open-source performance mods (Sodium, Lithium, FerriteCore, and others) whose licenses are fully respected. Release binaries are published on GitHub with SHA-256 hashes for verification. We are considering open-sourcing parts of the project in the future.
Does SolarClient work on Mac or Linux? ▼
Currently, SolarClient is Windows-only (Windows 10 and 11, 64-bit). Mac and Linux support are on the roadmap but do not have a release date yet. If cross-platform support is important to you, let us know in Discord so we can prioritize accordingly.
How is SolarClient different from Lunar Client or Feather? ▼
SolarClient focuses on being lightweight and transparent. Unlike Lunar Client, which uses a proprietary mod system, SolarClient uses standard Fabric/Forge mods that you can inspect, replace, or supplement. There is no mandatory telemetry, no cosmetics store, and no premium tier. The launcher is completely free, and ads only appear on this website—never inside the launcher itself.
