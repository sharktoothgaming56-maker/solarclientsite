Support & Troubleshooting

Common launcher problems with their actual causes, what to include when you report a bug, and how to reach us.

Contact

Discord is the fastest route. The people who write the code read the messages, and most questions get an answer within a few hours.

Installation problems

Expected. The installer is not code-signed, so Windows warns about an unrecognised publisher. Click More info, then Run anyway. Windows remembers your choice for that file.

If you want to verify first, open PowerShell in your Downloads folder and run Get-FileHash .\SolarClient-Setup-*.exe, then compare the result with the SHA-256 shown on the home page. The page pulls that value from the GitHub release, so it always matches the current build.

Unsigned installers that write files and launch other processes fit the heuristic profile some antivirus engines flag, and false positives on indie launchers are common. Check the VirusTotal link on the home page — it shows results for the exact build, across every engine.

If you are satisfied it is a false positive, restore the file and add an exclusion for the SolarClient install directory. If something looks genuinely wrong in the VirusTotal results, tell us in Discord before running anything, and include a link to the report.

Usually a permissions problem with the install location. Try installing to a directory under your user folder rather than Program Files, which requires elevation for every write.

If it still fails, check whether a previous installation left a partial directory behind and remove it before reinstalling.

Login problems

Almost always a stale cached session. Sign out in the launcher, then sign in again. If it persists, clear the launcher’s stored session from Settings → Account and start fresh.

Corporate or school networks sometimes block parts of Microsoft’s OAuth flow. If you are on one, try a different network to confirm.

The account you signed in with does not have a Java Edition entitlement. The usual causes: signing in with a different Microsoft account than the one that owns the game, owning Bedrock Edition rather than Java, or a recent purchase that has not finished propagating.

Confirm by signing in at minecraft.net with the same account and checking your profile. If the official launcher will not start Java Edition either, the problem is with the account rather than with us — Mojang support is the right place for that.

That should never happen, and if it did, you are not running our software. SolarClient sends you to Microsoft’s own login page and never handles your password.

If you typed a password into something claiming to be SolarClient, change your Microsoft password immediately and check your account’s recent sign-in activity. Then tell us in Discord — we want to know where the fake came from.

Game launch problems

The real error is in the log, printed before the process ended. Open the log from the launcher and read from the bottom up.

The two most common causes are a Java version mismatch and a mod incompatibility. UnsupportedClassVersionError means the Java version is too old for the game; InaccessibleObjectException means it is too new for the mod loader. Our Java version guide explains both and how to decode the numbers.

Counterintuitively, raising your allocation is not always the fix. If memory climbs steadily across a session and never returns to a baseline, something is leaking and a bigger heap only delays the crash.

Check the F3 memory readout. If the low points of the sawtooth keep rising over time, look for a leaking mod and add MemoryLeakFix. If the low points are stable but close to your ceiling, you genuinely need more — see the RAM guide for how much.

Graphics driver issue. Update to the current driver from NVIDIA, AMD or Intel directly rather than through Windows Update, which often lags well behind.

If the crash mentions a missing OpenGL version, your GPU or its driver does not support what the game requires. Minecraft needs OpenGL 4.5 for modern versions; very old integrated graphics cannot provide it.

Remove the most recently added mod and try again. If that is unclear, disable half the mods, test, and repeat on whichever half still fails — a binary search narrows it down in a handful of attempts even with a hundred mods.

The most common cause by far is a version mismatch. Performance mods in particular touch game internals and are strict: a build for 1.20.1 will usually not load on 1.20.4.

Performance problems

Performance questions have their own guides, because the answers are longer than a support entry:

  • Low frame rate — start with which GPU is actually running the game
  • Stutter and lag spikes — identify the cause from the frame time graph first
  • Memory and garbage collection — why more RAM often makes it worse
  • Shader performance — shadow settings dominate the cost

Reporting a bug well

A report with these five things usually gets fixed. A report that says “it crashes” usually gets a series of questions instead.

1. The SolarClient version. Shown in the launcher’s title bar and under Settings → About.

2. The Minecraft version and mod loader you were launching — for example 1.21.1 Fabric.

3. The full log or crash report, not a screenshot of part of it. Paste it to a text-sharing service and link it; the useful line is frequently not the one that looks important.

4. What you were doing when it happened, and whether it reproduces. “Every time I open the mod browser” is far more actionable than “sometimes”.

5. What you have already tried. Saves both of us repeating it.

If it is a performance problem rather than a crash, a spark profiler report is worth more than any description. Run /spark profiler start, play for a minute while the problem occurs, then /spark profiler stop and share the link it gives you.
