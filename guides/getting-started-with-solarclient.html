Getting Started with SolarClient

Everything you need for a clean first launch on Windows: download the installer, get past SmartScreen, sign in with Microsoft, pick a version, and understand what the launcher installs for you.

Published November 1, 2026 · Windows 10 / 11 · ~8 min read

Before you start

  • You need a Microsoft account that owns Minecraft: Java Edition.
  • SolarClient runs on Windows 10 or 11 (64-bit) only.
  • You do not need to install Java yourself.
  • The first run shows a Windows SmartScreen warning because the build is not code-signed. That is expected for an independent project.
  • You can verify the installer with the SHA-256 hash shown on the download section of the home page.

1. Download the installer

Open figgysmp.shop and use the Download button on the home page. The file name looks like SolarClient-Setup-<version>.exe. Prefer the link on this site or the GitHub Latest release — do not grab random mirrors.

Before you run it, compare the SHA-256 on the download card with the hash of the file you saved. If they differ, delete the file and download again. Matching hashes are the simplest way to confirm you have the file we published.

2. Windows SmartScreen

Because SolarClient is not code-signed with a paid certificate, Windows Defender SmartScreen often shows “Windows protected your PC.” Click More info, then Run anyway. That dialog is about reputation of unsigned software, not a VirusTotal finding. If you want a second opinion, submit the exact installer to VirusTotal yourself and compare the hash to the one on our site.

3. Sign in with Microsoft

Launch SolarClient and start Microsoft sign-in. A browser window opens on Microsoft’s own login page — the same OAuth flow the vanilla launcher uses. Type your password there, not into the launcher. When Microsoft finishes, it returns a session token to SolarClient on your PC. That token is refreshed locally when it expires; it is not sent to our advertising partners.

If sign-in fails, check that the account owns Java Edition, that you are not blocking the redirect in a strict browser, and that the system clock is roughly correct (OAuth tokens are time-sensitive).

4. Pick a Minecraft version

On the versions screen, choose the release you want to play. SolarClient downloads the game files from Mojang, selects a matching Java runtime, and attaches its curated Fabric performance stack for that version when one is available. If a version has no SolarClient mod build yet, the launcher still runs the game; it simply skips the SolarClient mod jar until one exists.

For most people starting today, the newest release branch is fine. Older versions matter for servers that have not updated. Our Java version guide explains which Java runtime each era of Minecraft expects if you ever need to debug by hand.

5. Allocate a sensible amount of RAM

More memory is not always better. Minecraft’s garbage collector pauses grow with a huge heap, which is why allocating 12–16 GB on an 16 GB machine often feels worse than 4–6 GB. A practical starting point:

  • 8 GB system RAM: allocate about 3–4 GB
  • 16 GB system RAM: allocate about 4–6 GB
  • 32 GB+ system RAM: allocate about 6–8 GB unless a huge modpack needs more

Leave headroom for Windows, your browser, Discord, and the GPU driver. The full reasoning is in How Much RAM Should You Allocate?

6. What the launcher installs for you

On a typical modern release, SolarClient attaches open-source performance mods such as Sodium, Lithium, and FerriteCore, version-matched so you are not mixing jars from different Minecraft builds. It also applies JVM flags scaled to the memory you chose. None of that replaces learning how the mods work — our performance mods reference and FPS guide go deeper if you want to tune further.

You can still add mods, shaders, and resource packs from the built-in Modrinth browser. Prefer Fabric mods that declare support for your exact game version.

7. Friends, chat, and online features

Optional online features — friends list, live chat, communities, voice — connect through SolarClient’s backend. They require the launcher to be online and a signed-in Minecraft account. They are not required to play singleplayer or join a normal multiplayer server. What those features store is listed in the privacy policy.

8. Updates

Stable builds update through the launcher’s update channel. Beta builds are optional and can change quickly. When something breaks after an update, check the changelog and Discord support channels before reinstalling from scratch.
